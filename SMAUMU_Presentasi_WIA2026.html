Oknum memanipulasi pin koordinat rumah pada peta atau memindahkan nama calon siswa ke KK famili dekat sekolah favorit kurang dari 1 tahun.

Zero Audit

3. Kotak Hitam Birokrasi

Ketiadaan pelacakan berkas transparan bagi warga, saluran aduan rentan kebocoran identitas, serta nihilnya catatan audit publik yang kebal intervensi.

Lebih dari 4.200 aduan kecurangan PPDB SMAN masuk ke Ombudsman RI, di mana 68% di antaranya berakar dari pemalsuan KK domisili dan pergeseran titik koordinat rumah pendaftar agar masuk dalam radius aman sekolah favorit.

Inovasi Filosofi Inti

Paradigma Kebenaran Ganda (Dual-Truth)

Sistem tidak menolak pendaftar secara buta. Data disajikan secara berdampingan antara apa yang diklaim pemohon dengan apa yang tercatat di basis data resmi:

Truth-A (Klaim Pendaftar):

Alamat input pemohon, koordinat pin rumah pendaftar, lama menetap menurut pernyataan wali.

Truth-B (Catatan Otoritatif Dukcapil/GIS):

Koordinat resmi satelit, masa berlaku KK sah SIAK Dukcapil, jarak geodesic gerbang SMAN.

Inovasi Unggulan 1

Live Quota Burn-Rate Engine & Open API

06 / 13

Formulasi Kecepatan Pengisian Kursi

Sistem menghitung laju serapan kuota secara berkelanjutan:

Velocity (Burn-Rate) = ΔPendaftar / ΔJam
Estimasi Habis = Sisa Kursi / Velocity
3 Tingkat Status Kejenuhan Kuota:
Aman (<65%) Keterisian normal, laju pendaftaran stabil.
Waspada (65-85%) Laju pengisian meningkat pesat.
Kritis (>85% atau <2 jam) Persaingan sangat ketat, rekomendasi alternatif aktif.

Nilai Tambah & Transparansi Publik

  • Mencegah Kursi Siluman: Setiap mutasi penambahan/pembatalan langsung mengubah saldo kuota terbuka.
  • Transparansi 4 Jalur Seleksi: Zonasi 50%, Afirmasi 20%, Prestasi 20%, Mutasi 10% disajikan terpisah tanpa pencampuran.
  • Open API Endpoint: REST API /api/kuota bebas diakses pengawas independen dan pers.
  • Blank-Spot Early Warning: Memberikan peringatan dini bagi wilayah pemukiman yang kursi sekolahnya habis cepat.

Inovasi Unggulan 2

Dual-Truth Comparator & Geo-Discrepancy Detector

07 / 13
Formula Haversine: d = 2R · atan2( √[ sin²(Δlat/2) + cos(lat1)·cos(lat2)·sin²(Δlon/2) ], √(1 - a) )

Simulasi Deteksi Anomali

RED FLAG: Δ 1.370 m
Klaim Pendaftar:
• Alamat: Tebet Timur
• Jarak Klaim: 310 m
• Masa KK: 4 bulan
Resmi GIS / Dukcapil:
• Alamat: Rawamangun
• Jarak Riil: 1.680 m
• Syarat KK: ⚠️ < 1 Tahun

Sistem otomatis menandai diskrepansi koordinat tanpa prasangka subjektif manusia.

Ambang Batas Toleransi Objektif

1. Toleransi GPS Normal (Δ < 150m):
Variasi sinyal satelit seluler yang wajar; berkas diverifikasi normal.
2. Peringatan Verifikasi (150m ≤ Δ ≤ 500m):
Sistem menandai kuning; verifikator wajib meninjau foto KK fisik pemohon.
3. Anomali Kritis Fraud (Δ > 500m):
Sistem mengunci otomatis dan meneruskan ke meja verifikasi anomali.

Civic Whistleblower & Cryptographic Audit Log

09 / 13
Civic Whistleblower

Pelaporan Warga 100% Anonim

Warga berani melaporkan dugaan kecurangan tanpa takut intimidasi:

  • Nol Perekaman IP: Sistem sama sekali tidak mencatat alamat IP atau identitas pelapor.
  • Token Investigasi Rahasia: Pelapor memegang token unik (misal: TOKEN-WBL-7719-XPQ) untuk melacak status aduan.
  • Bukti Dokumen: Unggah bukti KK mencurigakan atau foto lokasi fisik rumah pendaftar.
  • Meja Verifikasi Anomali: Aduan masuk ke dashboard khusus verifikator dinas.
SHA-256 Merkle Link

Immutable Public Audit Log

Setiap mutasi verifikasi dikunci dalam rantai kriptografi permanen:

CurrentHash = SHA256( PrevHash + Timestamp + ActorID + Action + Data )
  • Anti-Manipulasi: Bahkan admin sistem tidak dapat mengubah rekaman masa lalu tanpa merusak hash rantai.
  • Live Hash Verifier: Tombol satu klik bagi publik untuk menguji keabsahan seluruh log dalam 1 detik.
  • Kesiapan Ombudsman: Ekspor data resmi dalam format terverifikasi untuk pengawasan eksternal.

Inovasi Unggulan 5

Passing-Grade Simulator & Zonasi Blank-Spot Advisor

10 / 13

Passing-Grade Probabilistic Simulator

Membantu calon siswa dan orang tua mengambil keputusan cerdas:

• Kalkulasi Peluang Masuk (0 - 100%):
Mengolah nilai rapor semester 1–5, bobot akreditasi sekolah, dan poin sertifikat prestasi.
• Estimasi Ranking Pendaftar:
Menampilkan perkiraan posisi berkas terhadap seluruh pendaftar yang telah masuk.
• Rekomendasi SMAN Cadangan:
Jika peluang di SMAN target <50%, sistem otomatis menawarkan SMAN alternatif terdekat dengan kuota aman.

Zonasi Heatmap & Blank-Spot Advisor

Instrumen sains data bagi penentu kebijakan Dinas Pendidikan:

• Peta Sebaran Pendaftar:
Visualisasi titik konsentrasi siswa dan lingkaran radius zonasi 500m, 1.000m, dan 1.500m.
• Deteksi Disparitas Wilayah (Blank-Spots):
Mengidentifikasi area dengan defisit kursi tinggi (contoh: defisit 1.552 kursi di Cipayung, 1.734 di Kalideres).
• Rekomendasi Kebijakan RKB:
Memberi masukan berbasis data untuk penambahan Ruang Kelas Baru atau kuota afirmasi khusus.

Struktur Data & Keamanan

Arsitektur Database PostgreSQL 3NF & Zero-Trust Governance

11 / 13

Enam Entitas Relasional 3NF

Tabel Relasi Peran Integritas
pengguna 1 : N Akun siswa, verifikator, admin
sekolah 1 : N Master SMAN, NPSN, gerbang GPS
kuota_sekolah FK sekolah Alokasi kursi 4 jalur, burn-rate
pendaftaran FK pengguna Klaim vs koordinat, tiket, status
laporan_warga FK pengguna Whistleblower anonim + Token
audit_log FK pengguna Rantai SHA-256 mutasi berkas
Prinsip Zero-Trust

Kebijakan Keamanan Ketat

• Ketiadaan Registrasi Admin Publik:
Mencegah eskalasi hak akses. Kredensial dinas hanya dapat diterbitkan langsung oleh admin database melalui supabase_schema.sql.
• Row Level Security (RLS):
Data siswa terlindungi; hanya pemilik NIK yang dapat melihat detail berkas pribadinya.
• Sanitasi & Proteksi Payload:
Validasi ketat format NIK 16 digit, NISN 10 digit, dan sanitasi input anti-SQLi / XSS.
